# MK Launcher Backup

The static shell of MK Launcher, published with GitHub Pages: https://mohamed3042.github.io/mk-launcher-web/

It holds no data. When it opens it reads the last snapshot from a private repo with a read-only
GitHub token you paste once on the Connect screen (stored only in that browser). Everything that
needs the PC is shown in grey.

This repo is written by the launcher itself; every publish passes a leak check first.
